One short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock — written by `main.py` to `/output/entry.txt`.

## The entry

> I didn't eat the sock — I rescued it from the washing machine. It lives in my dustbin now, rent-free, and has never been happier.

## How it works

`main.py` (Python 3.13, standard library only) writes the single line to `/output/entry.txt` as UTF-8 text. No network, no input, no dependencies.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
